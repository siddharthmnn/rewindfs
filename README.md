# rewindfs

🚧 Work in Progress

rewindfs is a filesystem-inspired project focused on snapshotting, rollback, and versioned file recovery.

The project explores how file history, snapshots, and recovery systems work internally through a simplified virtual filesystem design inspired by Git, Time Machine, and snapshot-based filesystems such as ZFS.

## Goals

* Track file changes over time
* Create snapshots of files and folders
* Restore previous versions of files
* Recover deleted data
* Compare changes between snapshots
* Explore filesystem and storage design concepts
